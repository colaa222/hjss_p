# hjss_p

카카오톡과 이메일을 보내는 사내 발송 도구입니다.

사용할 수 있는 기능:

- 카카오톡 1건 발송
- 이메일 1건 발송
- 엑셀 전체 발송
- 실패건 재발송

## 1. 사용 전 확인

### 카카오톡 사용 시

- Windows PC에서 실행해야 합니다.
- 카카오톡 PC가 설치되어 있어야 합니다.
- 카카오톡에 로그인되어 있어야 합니다.
- 가능하면 카카오톡 메인창이 열려 있고 채팅 목록이 보이는 상태에서 시작합니다.
- 발송 중에는 마우스나 키보드를 건드리지 않는 것이 좋습니다.

### 이메일 사용 시

- 사내에서 안내한 환경변수 설정이 완료되어 있어야 합니다.

### 엑셀 사용 시

- 기본 파일은 `sample.xlsx`입니다.
- 엑셀 파일이 열려 있으면 저장이 안 될 수 있으므로 닫아두는 것이 좋습니다.

## 2. 설치 방법

처음 한 번만 설치하면 됩니다.

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
pip install openpyxl
pip install python-dotenv
```

## 3. 실행 방법

아래 명령으로 프로그램을 실행합니다.

```powershell
uvicorn main:app --reload
```

브라우저에서 아래 주소로 접속합니다.

```text
http://127.0.0.1:8000
```

화면에서 사용할 수 있는 버튼:

- `카카오톡 1건 발송`
- `이메일 1건 발송`
- `엑셀 전체 발송`
- `실패건 재발송`

## 4. 기본 사용 순서

1. 카카오톡을 켜고 로그인합니다.
2. 가능하면 카카오톡을 채팅 목록 화면으로 맞춥니다.
3. 위 명령으로 프로그램을 실행합니다.
4. 브라우저에서 `http://127.0.0.1:8000`에 접속합니다.
5. 단건 발송 또는 엑셀 발송을 실행합니다.
6. 화면의 요약 결과와 상세 로그를 확인합니다.

## 5. 엑셀 컬럼 사용법

`sample.xlsx`는 아래 컬럼 순서로 사용합니다.

| 열 | 컬럼명 | 설명 |
| --- | --- | --- |
| A | `channel` | 발송 채널. `kakao` 또는 `email` |
| B | `target` | 카카오톡 채팅방 이름 |
| C | `to_email` | 받는 이메일 주소 |
| D | `subject` | 이메일 제목 |
| E | `message` | 발송할 본문 |
| F | `send_status` | 발송 결과 상태 |
| G | `detail` | 상세 결과 메시지 |

### 채널별 입력 규칙

`channel = kakao`

- `target` 입력
- `message` 입력
- `to_email`, `subject`는 비워도 됩니다.

`channel = email`

- `to_email` 입력
- `subject` 입력
- `message` 입력
- `target`은 비워도 됩니다.

### 상태 컬럼 의미

- `send_status = 1` : 성공
- `send_status = 0` : 실패
- 빈값 : 아직 미발송

`detail`에는 실패 단계와 상세 사유가 기록됩니다.

### 입력 예시

| channel | target | to_email | subject | message |
| --- | --- | --- | --- | --- |
| kakao | 임상민 |  |  | 테스트 메시지 |
| email |  | user@example.com | 안내 메일 | 안녕하세요 |

## 6. 엑셀 발송 방법

1. `sample.xlsx`를 엽니다.
2. 필요한 행에 내용을 입력합니다.
3. 파일을 저장하고 닫습니다.
4. 웹 화면에서 `엑셀 전체 발송`을 누릅니다.
5. 발송 후 `F열`, `G열` 결과를 확인합니다.

## 7. 실패건 재발송 방법

웹 화면의 `실패건 재발송` 버튼은 `F열(send_status)`가 `0`인 행만 다시 발송합니다.

권장 순서:

1. 실패한 행의 `F열` 값이 `0`인지 확인합니다.
2. 카카오톡을 다시 채팅 목록 화면으로 맞춥니다.
3. 웹 화면에서 `실패건 재발송`을 누릅니다.
4. 결과를 다시 확인합니다.

## 8. 실패 시 확인 포인트

아래 순서로 확인하면 됩니다.

- 카카오톡이 실제로 켜져 있는지
- 카카오톡이 로그인된 상태인지
- 카카오톡이 채팅 목록 상태인지
- 채팅방 이름이 카카오톡에서 검색 가능한 이름인지
- 엑셀의 `channel` 값이 `kakao` 또는 `email`인지
- 필수 컬럼이 비어 있지 않은지
- 같은 내용을 아주 짧은 시간 안에 반복 발송해 중복 차단이 걸린 것은 아닌지

웹 화면 또는 결과 로그에서 주로 보는 값:

- `request_id`
- `step`
- `message`
- `total`
- `success`
- `fail`

## 9. 주의사항

- 카카오톡 발송은 Windows 전용에 가깝습니다.
- 카카오톡 화면 상태가 다르면 실패할 수 있습니다.
- 발송 중 다른 창을 클릭하면 실패할 수 있습니다.
- 같은 대상에 같은 내용을 연속으로 보내면 중복 방지로 건너뛸 수 있습니다.
