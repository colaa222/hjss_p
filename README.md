# hjss_p

Windows PC에서 카카오톡 PC를 자동화해 메시지를 보내는 내부용 도구입니다.

이 리포는 두 가지 방식으로 사용할 수 있습니다.

- 웹 방식: 브라우저에서 1건 발송, 엑셀 전체 발송, 실패건 재발송
- 로컬 방식: 파이썬 스크립트로 `sample.xlsx` 전체 발송

## 1. 시작 전 준비

반드시 아래 상태에서 시작하는 것을 권장합니다.

- 카카오톡 PC가 켜져 있어야 합니다.
- 카카오톡에 로그인되어 있어야 합니다.
- 가능하면 메인창이 열려 있고 채팅 목록이 보이는 상태에서 진행합니다.
- 엑셀 파일이 열려 있으면 저장 충돌이 날 수 있으므로 닫아두는 것이 안전합니다.

이 프로젝트는 카카오톡 UI를 직접 조작하므로, 카카오톡 화면 상태가 꼬여 있으면 발송 실패가 날 수 있습니다.

## 2. 설치

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
pip install openpyxl
```

- `requirements.txt`: FastAPI 웹 실행용 패키지
- `openpyxl`: 엑셀 읽기/쓰기용 패키지

## 3. 엑셀 형식

기본 입력 파일은 루트의 `sample.xlsx`입니다.

컬럼 규칙:

- `A열`: 채팅방 이름 또는 대상 이름
- `B열`: 보낼 메시지
- `C열`: 발송 상태
- `D열`: 상세 메시지

상태값 규칙:

- `1`: 발송 성공
- `0`: 발송 실패
- 빈값: 아직 미발송

코드는 2행부터 읽습니다.  
`A열`과 `B열`이 모두 비어 있는 행을 만나면 읽기를 종료합니다.

## 4. 실행 방법

### 웹 방식

서버 실행:

```powershell
uvicorn main:app --reload
```

브라우저 접속:

```text
http://127.0.0.1:8000
```

웹 화면에서 가능한 작업:

- `1건 발송`
- `엑셀 전체 발송`
- `실패건 재발송`

사용 순서:

1. 카카오톡을 채팅 목록 화면으로 맞춥니다.
2. 서버를 실행합니다.
3. 브라우저에서 `http://127.0.0.1:8000`으로 접속합니다.
4. 필요한 버튼을 실행합니다.
5. 화면의 요약 결과와 상세 로그를 확인합니다.

### 로컬 방식

로컬 스크립트 실행:

```powershell
python scripts\test_excel_send.py
```

사용 순서:

1. 카카오톡을 채팅 목록 화면으로 맞춥니다.
2. `sample.xlsx`의 `A열`, `B열`을 채웁니다.
3. 위 스크립트를 실행합니다.
4. 실행 후 `C열`, `D열`에 기록된 결과를 확인합니다.

## 5. 실패 시 확인 포인트

실패가 나면 아래 순서로 확인하면 됩니다.

- 카카오톡이 실제로 켜져 있는지
- 카카오톡 메인창이 로그인된 정상 상태인지
- 채팅 목록이 보이는 상태인지
- 대상 이름이 카카오톡 채팅 검색으로 찾을 수 있는 이름인지
- 같은 메시지를 5초 이내에 다시 보내서 중복 차단(`dedup_skip`)이 걸린 것은 아닌지
- 엑셀의 `A열`, `B열`이 비어 있지 않은지

현재 응답/로그에서 특히 볼 항목:

- `request_id`: 요청 추적용 ID
- `step`: 어느 단계에서 실패했는지
- `message`: 실패 메시지
- `ui_state_before_reset`: 조작 전 카카오 메인 화면 추정 상태
- `ui_state_after_reset`: 최소 ESC 처리 후 카카오 메인 화면 추정 상태
- `selected_search_edit`: 실제로 선택된 채팅 검색창 핸들
- `fg_ok`: foreground 전환 성공 여부
- `focus_ok`: 검색창 또는 입력창 focus 확보 여부
- `chat_hwnd`: 실제 채팅창 확보 여부
- `logs`: 상세 단계 로그

대표적인 실패 해석:

- `find_kakao_main_window`: 카카오톡 메인창을 찾지 못함
- `inspect_kakao_ui_state`: 현재 화면이 채팅 검색 가능한 상태가 아님
- `validate_chatroom_search_edit`: 선택된 Edit가 실제 채팅 검색창으로 검증되지 않음
- `open_chatroom_by_search.foreground`: 메인창을 앞으로 가져오지 못함
- `open_chatroom_by_search.focus_search_edit`: 검색창 focus 실패로 Enter를 보내지 않음
- `open_chatroom`: Enter를 보냈지만 `chat_hwnd`를 확보하지 못함
- `send_chat_text.focus_input`: 채팅 입력창 focus 실패
- `dedup_skip`: 최근 5초 내 동일 요청으로 중복 발송 방지됨

## 6. 재발송 방법

### 웹에서 실패건 재발송

웹 화면의 `실패건 재발송` 버튼은 `C열(send_status)`이 `0`인 행만 다시 발송합니다.

재발송 순서:

1. 이전 실행 결과에서 실패한 행의 `C열` 값이 `0`인지 확인합니다.
2. 카카오톡을 다시 채팅 목록 상태로 맞춥니다.
3. 웹 화면에서 `실패건 재발송` 버튼을 누릅니다.
4. 결과 요약과 상세 로그를 확인합니다.

### 엑셀 기준 수동 재발송

웹 버튼 대신 수동으로 관리하려면 아래 방식으로도 가능합니다.

1. `C열`이 `0`인 실패 행만 남기거나 별도 파일로 정리합니다.
2. 성공 행은 제거하거나 `A열`, `B열`을 비웁니다.
3. 다시 `엑셀 전체 발송` 또는 `python scripts\test_excel_send.py`를 실행합니다.

## 7. 주요 파일

- `main.py`: FastAPI 엔트리
- `templates/index.html`: 웹 UI
- `app/kakao_win.py`: 카카오톡 UI 자동화
- `app/excel_service.py`: 엑셀 읽기/쓰기
- `app/sender.py`: 다건 발송 및 중복 발송 방지
- `scripts/test_excel_send.py`: 로컬 배치 실행 스크립트

## 8. 주의

- 이 프로젝트는 `pywin32` 기반이라 Windows 전용입니다.
- 카카오톡 UI 변경 시 자동화가 깨질 수 있습니다.
- 발송 중에는 마우스/키보드 개입으로 focus가 바뀌면 실패할 수 있습니다.
- 같은 대상과 같은 메시지를 아주 짧은 시간 안에 반복 요청하면 중복 방지 로직이 작동할 수 있습니다.
